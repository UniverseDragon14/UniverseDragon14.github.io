Raspberry Pi 5 evidence

The public proof record documents a GHZ3 200,000-shot Raspberry Pi 5 run with exact source/QBC histogram agreement on the referenced V10 Guardian development branch. The evidence document also records the exact source identity and distinguishes that evidence branch from the public main branch.

Branch boundary matters

The public QBIT NOVA Native README states that public main does not currently contain all later Stage6 GPU-routing, Stage7 typed-runtime or V10 data/Guardian development files. Therefore a proof document can establish source identity and a development-branch result without pretending every later implementation is already present on public main.
