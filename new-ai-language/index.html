QBIT NOVA Native

QBIT NOVA Native is the current public language/runtime research project in the Universal Dragon ecosystem. It is implemented in native C17 and combines deterministic compilation, QBC bytecode, QVM execution, software state-vector simulation and approval-first security.

What QBIT NOVA Native is

It is a programming-language/runtime research preview. Source examples currently use the .qn extension. The native pipeline covers deterministic lexing and parsing, typed intermediate representation, QBC bytecode, QVM execution and security controls around sensitive actions.

Runtime direction

  • Native C17 implementation
  • Deterministic QBC/QVM runtime
  • Software state-vector simulation
  • Reproducible execution results and receipts
  • No Python runtime dependency in the current truth boundary

Security direction

  • Deny-by-default capability guard
  • OpenSSL Ed25519 signed approvals
  • Trusted issuer checks
  • Persistent replay ledger
  • Token and issuer revocation lookup foundation
  • Revocation execution wiring remains pending
