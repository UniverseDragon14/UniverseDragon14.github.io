## QBIT NOVA Native

The current public QBIT NOVA project is **QBIT NOVA Native**.

The public repository describes it as:

> Native C17 programming language, deterministic QBC/QVM runtime, software virtual QCPU, and approval-first execution security.

Current source examples use the **`.qn`** extension.

### Truth boundary

```text
physical_qpu=false
runtime=software_virtual_qcpu
python_dependency=false
release_class=research_preview
```

QBIT NOVA Native does **not** claim that Raspberry Pi 5, phones or ordinary classical computers become physical quantum computers.

### Publicly documented pipeline

```text
QBIT NOVA source (.qn)
→ deterministic lexer
→ parser
→ typed AST → typed QIR
→ QBC bytecode
→ QVM
→ capability guard
→ authenticated approval
→ trusted issuer
→ replay protection
→ bounded execution
→ evidence receipt
```

### Publicly documented security status
